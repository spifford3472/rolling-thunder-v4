### Checkpoint 6B physical validation result — 2026-09-29

The owner-supervised CAT PTT test passed with the FT-891 connected to a dummy load. The radio visibly entered transmit from `TX1;`, and the bounded sequence completed through `TX0;`. No audio playback, Standard-port control, RTS, or DTR was used. Production service ownership of Enhanced CAT was restored after the test.

No persistent host setting, systemd unit, udev rule, ALSA default, radio menu value, or production configuration was changed by this validation, so there is no host rollback action associated with the Checkpoint 6B test.

### Checkpoint 6C physical validation result — 2026-09-29

The first DigiRig playback-only test keyed the FT-891 because mono playback reached the DR-891 right-channel VOX/PTT path. The implementation was corrected to explicit stereo with FT8 audio on the left channel and silence on the right.

The corrected owner-supervised retest passed: the FT-891 remained in receive for the entire finite playback, no RF transmission occurred, and the DigiRig playback device was released afterward.

No persistent host setting, ALSA default, systemd unit, udev rule, radio menu value, or production configuration was changed by the corrected test.

### Checkpoint 6D CAT PTT + meter isolation result — 2026-09-29

A supervised dummy-load test keyed the FT-891 in DATA mode for about three seconds with no playback audio. CAT ALC, power, and SWR meter reads succeeded repeatedly while keyed, and CAT release returned the radio to receive. The steady no-audio readings were approximately ALC=002, POWER=001, SWR=000 raw; the first ALC sample immediately after keying was a transition value of 252.

The immediate post-release attempt to restore USB failed verification because the radio still read DATA. Future CP6 hardware test cleanup must allow a short receive-settle interval before restoring the prior mode. Production was restarted successfully.

### Checkpoint 6D harness refinements — 2026-09-29

Owner-side CP6D cleanup now includes a 0.5-second receive-settle delay before restoring the original mode. Meter summaries retain the complete raw log but exclude the first two post-key samples from steady-state maxima so key-up transients are not misinterpreted as sustained ALC/power/SWR behavior.

### Checkpoint 6D full combined FT8 dummy-load test — 2026-09-29

The combined CAT-PTT plus left-only FT8 playback test completed successfully into the dummy load and returned to RX normally. Cleanup was clean and production restarted.

Observed sustained CAT meter values during modulation were approximately ALC 115-128 raw, POWER 31-35 raw, and SWR 255 raw. The owner confirmed the homemade dummy load used for this test has known high SWR, while the normal antenna does not, so the high raw SWR reading is attributed to the test load rather than the CP6 transmit path. Elevated ALC remains the item to investigate before antenna-based transmission.

### Checkpoint 6D ALC optimization — DATA DATA GAIN 25

Reducing FT-891 menu 16-14 DATA DATA GAIN from 50 to 25 significantly lowered sustained raw ALC from roughly 115-128 to about 24-35 while preserving approximately the same raw power range at the configured 5 W level. The dummy load's known high SWR remained visible as raw SWR 255 during modulation. Menu 16-14 is currently set to 25 and is a reversible radio-side change.

### Checkpoint 6D ALC optimization — DATA DATA GAIN 20

At FT-891 menu 16-14 DATA DATA GAIN = 20, sustained raw ALC fell to approximately 2-9 while raw power remained approximately 29-35 at the configured 5 W level. This is the best observed ALC result so far and preserves the same output behavior seen at higher gain settings. The homemade dummy load continued to report raw SWR 255 during modulation. Menu 16-14 is currently set to 20 and is a reversible radio-side change.
