# Pipe-only WSJT-X WSPR decoder

This standalone WSPR-2 decoder adapts `lib/wsprd` from [WSJT-X commit 967c85a6119110788b0df3782cf796485b2cee14](https://github.com/WSJTX/wsjtx/tree/967c85a6119110788b0df3782cf796485b2cee14/lib/wsprd). The upstream copyrights apply. See [COPYING](COPYING) for its GPL terms. Rolling Thunder talks to this separately built executable through stdin and stdout.

`wsprd_pipe.c` retains upstream demodulation, Fano decoding, per-slot hash handling, and duplicate detection. Its only normal input is one 114-second, 12 kHz, signed 16-bit mono little-endian PCM window on stdin, with the receiver dial frequency supplied in Hz as the first argument. It streams up to 50 rows followed by `<DecodeFinished>` to stdout. Each row contains signal-to-noise ratio in dB, time offset in seconds, RF frequency in Hz, drift, callsign, optional grid, and transmit power in dBm. `--protocol` reports the interface version.

The adaptation removes upstream audio files, journal files, timing files, FFT wisdom, disk-backed hash state, and optional OSD/Fortran decoding. A type-3 encoded callsign can only be resolved against another spot in the same window. PCM and the hash state expire with each process. Core dumps are disabled before reading PCM. The caller owns UTC alignment, process deadline and cancellation, validation, and online reporting.

The normal Rolling Thunder package build on Linux includes the helper when the host has a C compiler and the single-precision FFTW development package. On Debian-family hosts that package is `libfftw3-dev`. The build does not fetch sources or dependencies and supports the unchanged editable-install release path. The resulting executable is installed in the same environment's script directory. Python-only installations can start the normal application and show WSPR decoder unavailable. If the FFTW headers are present but the native build fails, installation fails so deployment can follow its standard failure path.

Native offline validation can send the standard WSJT-X sample `samples/WSPR/150426_0918.wav` as raw PCM with dial frequency 10138700. For example, Python's `wave` module can read the first 1,368,000 frames and pass them to the child with `subprocess.run(input=pcm, capture_output=True)`. Expected rows include ND6P in DM04 and W3BI in FN20. No WSPR receiver or reporting service is needed for this validation.
